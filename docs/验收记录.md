# Chrome Locale SG 0.2.0 验收摘要

验证日期：2026-10-10。平台：macOS，官方 Chrome for Testing 155.0.8059.39，独立临时 Profile。

本文件适合随源码发布，不含个人账号、本机用户路径、浏览器 profile 数据或原始进程日志。原始证据由测试工具在本机生成到 test-results，该目录不进入发布源码。

## 本轮目标

- 默认语言只有 `zh-SG`、`en-US`；请求头 `zh-SG,en-US;q=0.9`。
- 新安装默认总开关开启、所有 HTTP / HTTPS 网站生效。
- 自动启动、持久化规则与注册；自动补同步已存在的网页。
- SG 图标上的状态灯、中文角标与当前页真实检测联动。
- 提供可跨 Profile / 机器使用的 ZIP；安装使用不需要开发环境。

- 四次浏览器进程启动、三次完整退出后重启。无需手工打开 Popup 的启动补同步和角标恢复均通过。

## 原生 UI 目视核对

在独立测试 Profile 的扩展菜单中看到“在所有网站上始终允许”。实际固定到工具栏后，SG 图标右上角显示绿色小圆点，角标为“开”，悬停/可访问性文字显示“此页已生效”。

实际从 Popup 关闭后，实时值恢复测试 Profile 的原生语言，请求头规则变为“无规则”；工具栏显示灰灯与“关”。重新开启后恢复绿灯与“开”。没有借助修改日常 Chrome 配置来验证。

## 如实记录的启动限制

严格的首次启动网页测试曾失败：在命令行加载临时测试扩展时，浏览器的第一个导航早于扩展就绪；首段脚本与第一笔主文档请求仍读到原始值。旧实现还没有主动补同步这个页面。

现实现增加 startup 对已有页面的同步，以及导航完成时的补同步。验收要求自动恢复目标值与正确角标，无需开 Popup 或刷新；**不能因此把最初的原始读值或请求头改记为成功**。该项保留原始证据并单列 limitation，持久化安装和所有恢复标签情形不作未经验证的保证。

## 其他边界

- 自定义语言仍有异步下发窗口；默认两语言使用同步预设。
- Worker 的语言与原生 Locale、部分内建 toLocaleString、原生 constructor 入口和空 locale 列表仍可能暴露原始环境。
- Windows/Linux、普通 Chrome 既有 Profile、首次 UI 安装权限流程、所有企业策略及全部 sandbox 组合未逐一实测。
- 浏览器启动后自动恢复，不等于隐藏 Chrome 的开发者扩展或测试浏览器说明；本扩展不使用或隐藏调试提示。
- 另一台机器或另一份 Profile 需要各加载一次；设置彼此独立，不宣称 GitHub Release 能替代商店安装/自动同步。
